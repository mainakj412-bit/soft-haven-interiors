## Editing the site

**Edit `_page.src.html`. Nothing else.** `index.html` and `_page.html` are both
generated from it, and any change made directly to them is lost on the next build.

```powershell
# 1. edit _page.src.html
# 2. regenerate index.html (hosted) and _page.html (preview build)
.\_scripts\build.ps1
# 3. refresh the folder GitHub Pages serves
.\_scripts\package_site.ps1
# 4. publish
git add -A; git commit -m "Describe the change"; git push
```

The live site updates about a minute after the push.

## Layout

| Path | What it is |
|---|---|
| `_page.src.html` | The source. The only file to edit. |
| `index.html` | Generated: standalone page, images as separate files. |
| `_page.html` | Generated: every photo inlined as base64, for preview links. Not committed. |
| `docs/` | What GitHub Pages serves. Regenerated by `package_site.ps1`. |
| `images/` | Site photos, plus `fabrics/sh-01…33.jpg` for the catalogue. |
| `images/_raw/`, `images/_materials_raw/` | Untouched originals. Not committed. |
| `_scripts/` | Build and image-processing scripts. |

## Scripts

- `build.ps1` — regenerates `index.html` and `_page.html` from the source.
- `package_site.ps1` — copies the live site into `docs/` and zips it.
- `build_index.py` — the `index.html` step of `build.ps1` for machines without PowerShell; also copies it into `docs/`. Does not build `_page.html` or copy images.
- `process_photos.ps1` — crops and resizes the gallery photos.
- `process_fabrics.ps1` — turns the fabric shop photos into coded `sh-NN.jpg` files.
- `make_logo.ps1` — cuts `logo.png` and `logo-mark.png` from the original.

## Two things to keep in mind

**Image paths must be written out in full in `_page.src.html`.** The preview build
swaps them for inline data URIs using plain text replacement, so a path assembled in
JavaScript (`'images/fabrics/sh-' + n + '.jpg'`) silently fails to embed.

**Fabric codes identify a photo, not a single roll.** Each shop photo holds four or
five rolls, so `SH-17` means "that shelf". The WhatsApp message asks the customer
which colour they mean. Single-roll photos would fix this properly.
